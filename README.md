# WB Leads Automation

Инструмент для сбора лидов с Wildberries и рассылки им в WhatsApp. Всё управляется через локальный веб-интерфейс в браузере.

## Что он делает

Работает в три последовательных этапа:

1. **Парсинг.** По поисковым запросам проходит выдачу Wildberries (через расширение mpstats), отбирает карточки по заданным фильтрам (цена, выручка, отзывы, рейтинг, параметры продавца и т.д.) и **пропускает карточки, где на первом слайде видео**. Из подходящих карточек собирает продавцов-ИП и сохраняет их в базу.

2. **Пробив.** Собранных продавцов «пробивает» через Telegram-бота: по данным ИП достаёт телефон, почту и дату рождения. Результат дописывается к каждому продавцу.

3. **Рассылка.** Найденным телефонам шлёт сообщение (текст + при желании фото/видео) через WhatsApp Web — автоматизация кликает по интерфейсу WhatsApp, проверяет, что номер зарегистрирован, и отправляет.

## Аккаунты, которые нужны

- **Chrome-профиль с mpstats** — для парсинга WB. Профиль с установленным расширением mpstats, залогиненный.
- **Telegram-аккаунт** — для пробива (через него общается с ботом). Добавляется в интерфейсе: телефон → код → пароль (2FA). Нужен прокси.
- **WhatsApp-аккаунт(ы)** — для рассылки. Добавляется в интерфейсе: открывается окно браузера, сканируешь QR в телефоне. Для каждого аккаунта **обязателен прокси** (каждый аккаунт — своё отдельное окно/профиль).

## Установка

Нужен Python 3.11+ и установленный Google Chrome.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

Создать файл настроек из шаблона и вписать свои ключи:

```bash
copy .env.example .env
```

В `.env` заполнить как минимум `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — их бесплатно выдают на https://my.telegram.org (нужны для подключения Telegram-аккаунта к пробиву).

## Запуск

```bash
python run_web.py
```

Открыть в браузере: **http://127.0.0.1:8000**

Дальше весь процесс идёт через интерфейс: подключаешь аккаунты (Chrome-профиль, Telegram, WhatsApp), создаёшь задачу парсинга с нужными фильтрами, запускаешь → пробив → рассылка. Логи каждой задачи видно прямо в веб-интерфейсе.

## Структура

```
run_web.py              # запуск веб-сервера
web/                    # веб-интерфейс (FastAPI + статика)
src/wb/                 # парсинг Wildberries и пробив
src/whatsapp/           # рассылка через WhatsApp Web
src/telegram/           # подключение Telegram-аккаунтов
src/core/               # база (SQLite), конфиг, логи
data/                   # рабочие данные (создаётся автоматически, в репозиторий не коммитится)
```

## Примечания

- Все данные (сессии, базы, профили браузеров, логи) хранятся локально в `data/`, `sessions/`, `logs/` и в git не попадают.
- Селекторы WhatsApp Web привязаны к текущему интерфейсу WhatsApp — если WhatsApp обновит вёрстку, их, возможно, придётся поправить в `src/whatsapp/broadcaster.py`.
- Пробив работает через сторонний Telegram-бот — он должен быть доступен с подключённого аккаунта.
